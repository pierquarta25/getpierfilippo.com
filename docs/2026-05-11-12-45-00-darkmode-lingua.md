
# Progetto: Implementazione Funzionalità Navbar (Dark Mode & Lingua)

**Data:** 2026-05-11
**Stato:** In Corso
**Autore:** Gemini CLI

## Obiettivo
Rendere funzionali i pulsanti per il cambio lingua (EN/IT) e l'attivazione della modalità scura (Dark Mode) all'interno della `TopBar`.

---

## 1. Modalità Scura (Dark Mode)

### Opzione A: Libreria `next-themes` (Consigliata)
Utilizzare la libreria standard per Next.js che gestisce automaticamente la persistenza nel localStorage e la prevenzione del flash di colore.
- **Implementazione:** Installazione di `next-themes`, creazione di un `ThemeProvider` e uso dell'hook `useTheme`.
- **Vantaggi:** Robusto, gestisce le preferenze di sistema.

### Opzione B: Gestione Manuale con Classe CSS
Gestire manualmente una classe `.dark` sull'elemento `html` tramite state.
- **Implementazione:** `document.documentElement.classList.toggle('dark')`.
- **Vantaggi:** Nessuna dipendenza esterna.

### Opzione C: Utilizzo delle Variabili Tailwind v4
Sfruttare le nuove funzionalità di Tailwind v4 per la gestione dei temi.

---

## 2. Cambio Lingua (i18n)

### Opzione A: Stato Locale (Semplice)
Utilizzare un semplice stato React per cambiare le stringhe visibili.
- **Vantaggi:** Ideale per portfolio con poco testo, implementazione rapida.

### Opzione B: Routing con `next-intl`
Implementare una struttura a cartelle `[locale]` per gestire le rotte.
- **Vantaggi:** SEO friendly, standard industriale.

### Opzione C: Sistema Custom a Context
Creare un `LanguageProvider` che distribuisce le traduzioni in tutta l'app.
- **Vantaggi:** Flessibile senza modificare la struttura delle URL.

---

## Scelta Proposta
- **Dark Mode:** **Opzione A** (`next-themes`) per la massima affidabilità.
- **Lingua:** **Opzione C** (Context API custom) per permettere il cambio lingua immediato senza complicare il routing in questa fase.

## Piano d'Azione
1. Installare `next-themes` (`npm install next-themes`).
2. Creare un componente `Providers.tsx` per avvolgere l'applicazione.
3. Creare un `LanguageContext` semplice per gestire IT/EN.
4. Aggiornare `TopBar.tsx` per collegare gli hook necessari.
