# Project Design Document: AI Chat Widget

## Obiettivo
Integrare un assistente virtuale AI all'interno del sito portfolio tramite un Chat Widget fluttuante, capace di rispondere a domande sull'esperienza, i progetti e le competenze di Pierfilippo.

## Architettura Tecnica
- **Framework UI:** React (Next.js App Router)
- **Styling:** Tailwind CSS + shadcn/ui (per componenti accessibili e design moderno)
- **Gestione Stato & Streaming:** Vercel AI SDK (`useChat` hook)
- **Modello AI (Provider):** Da definire (Opzioni: Google Gemini, Groq/Llama3, OpenAI)

## Componenti da Sviluppare
1. `ChatWidget.tsx`: Il componente contenitore principale, posizionato in `fixed bottom-4 right-4`.
2. `ChatMessage.tsx`: Componente per visualizzare i singoli messaggi.
3. `api/chat/route.ts`: L'endpoint API Route che gestisce la logica lato server e restituisce la risposta in streaming.

## System Prompt (Istruzioni per l'AI)
Il sistema includerà un prompt nascosto simile a:
> "Sei l'assistente virtuale di Pierfilippo Quartarella. Il tuo compito è rispondere a domande sui suoi progetti e le sue competenze in modo cortese e professionale."

## Fasi di Implementazione
1. Installazione dipendenze (`ai`, `@ai-sdk/...`).
2. Creazione dell'API Route per lo streaming.
3. Sviluppo interfaccia grafica (pulsante fluttuante e finestra chat).
4. Integrazione logica `useChat` e test.
5. Inserimento dei dati contestuali (CV/Progetti) nel System Prompt.
